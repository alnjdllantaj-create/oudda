  عُدّة / Oudda — الريبو الجاهز لـ GitHub + Netlify

هاد المجلد هو الكود المصدري كامل (82 ملف). Netlify كيبنيه أوتوماتيكياً
من بعد ما تربط الريبو — ما كيحتاج حتى ZIP آخر.

✅ ملف netlify.toml فيه:
     command = "npm run build"
     publish = "out"
     NODE_VERSION = "22"
     NEXT_PUBLIC_SITE_URL = "https://oudda-content.netlify.app"
     NEXT_PUBLIC_CONTACT_EMAIL = "alnjdllantaj@gmail.com"

⚠️ منين تشري نطاقاً خاصاً، بدّل NEXT_PUBLIC_SITE_URL فـ netlify.toml
   (قولّي أنـا وكنبدّلو لك فالملف).
